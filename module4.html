1. NumPy — Arrays and Vectorized Operations

What is NumPy?

NumPy (Numerical Python) is Python's foundational package for numerical computation. Its core data structure is the ndarray — a fixed-type, contiguous-memory, multi-dimensional array that enables vectorized operations: applying a computation to an entire array at once rather than element-by-element in a Python loop. NumPy operations run at C-speed, making them 10–100× faster than equivalent Python loops for numerical work.

1.1 Creating Arrays

import numpy as np

# From Python lists
a = np.array([1, 2, 3, 4, 5])          # 1-D array, dtype=int64
b = np.array([[1,2,3],[4,5,6]])        # 2-D array, shape=(2,3)

# Factory functions
np.zeros((3,4))           # 3×4 array of zeros
np.ones((2,3))            # 2×3 array of ones
np.arange(0, 10, 2)      # [0, 2, 4, 6, 8]
np.linspace(0, 1, 5)     # [0.0, 0.25, 0.5, 0.75, 1.0]
np.eye(3)                 # 3×3 identity matrix
np.random.rand(4, 3)     # random floats in [0, 1), shape (4,3)
np.random.randn(1000)    # 1000 standard normal draws

# Key attributes
a.shape       # (5,)  — dimensions
a.ndim        # 1     — number of dimensions
a.dtype       # dtype('int64')
a.size        # 5     — total elements

1.2 Vectorized Operations (No Loops Needed)

import numpy as np

prices  = np.array([100, 200, 150, 300, 250])  # prices in ₹
discounts = np.array([0.1, 0.2, 0.15, 0.0, 0.05])

# Arithmetic — applied element-wise automatically
final_prices = prices * (1 - discounts)
# [ 90. 160. 127.5  300. 237.5 ]

# Universal functions (ufuncs)
np.sqrt(prices)       # square root of each element
np.log(prices)        # natural log (useful for log-transforming skewed data)
np.abs(prices - 200) # absolute deviation from 200

# Reduction functions
np.sum(prices)         # 1000
np.mean(prices)        # 200.0
np.std(prices)         # 70.71
np.median(prices)      # 200.0
np.min(prices), np.max(prices)  # 100, 300
np.percentile(prices, [25, 50, 75])  # [137.5, 200.0, 262.5]

1.3 Boolean Indexing and Masking

import numpy as np

scores = np.array([45, 72, 88, 60, 95, 38, 77])

# Boolean mask — each element evaluates to True/False
passed = scores >= 60           # [F, T, T, T, T, F, T]

# Use mask to filter
passing_scores = scores[passed]  # [72, 88, 60, 95, 77]

# Combine conditions
high_pass = scores[(scores >= 75) & (scores < 90)]  # [88, 77]

# Count and proportion
np.sum(passed)         # 5 students passed
np.mean(passed)        # 0.714 — 71.4% pass rate

# np.where — vectorized if-else
grade = np.where(scores >= 60, 'Pass', 'Fail')
# ['Fail', 'Pass', 'Pass', 'Pass', 'Pass', 'Fail', 'Pass']

1.4 Broadcasting

Broadcasting is NumPy's mechanism for performing arithmetic between arrays of different shapes. Rather than requiring the same shape, NumPy stretches smaller arrays to match larger ones — without copying data.

import numpy as np

# Standardize a matrix (each column to mean=0, std=1)
data = np.array([[10, 200, 1.5],
                  [12, 250, 2.1],
                  [8,  180, 0.9]])   # shape (3, 3)

col_mean = data.mean(axis=0)          # shape (3,) — mean of each column
col_std  = data.std(axis=0)           # shape (3,)

# Broadcasting: (3,3) - (3,) → (3,3) - (1,3) expanded → works
standardized = (data - col_mean) / col_std
# Each column now has mean≈0 and std≈1

2. Pandas — Series and DataFrames

Core Data Structures

Pandas provides two primary data structures: a Series (a 1-D labelled array — like a single table column with an index) and a DataFrame (a 2-D labelled table of columns, analogous to a spreadsheet or SQL table). Every DataFrame column is a Series.

2.1 Creating DataFrames

import pandas as pd

# From a dictionary

# Inspect

# Assume df has index 0,1,2,3 and columns: customer_id, name, spend, city

── .loc — label-based ──────────────────────────────────────
df.loc[0]                       # row with index label 0
df.loc[0:2]                    # rows with labels 0,1,2 (INCLUSIVE end)
df.loc[0:2, 'name':'spend']  # rows 0-2, columns 'name' to 'spend'
df.loc[df['spend'] > 1000]    # boolean mask — high spenders

── .iloc — position-based ──────────────────────────────────
df.iloc[0]                      # first row
df.iloc[0:2]                   # rows 0,1 (EXCLUSIVE end, like Python slices)
df.iloc[:3, 1:3]              # first 3 rows, columns at positions 1 and 2
df.iloc[-1]                    # last row

── Multi-condition filtering ────────────────────────────────
mask = (df['city'] == 'Mumbai') & (df['active'] == True)
df[mask]

# .query() — readable alternative to boolean masks
df.query("city == 'Mumbai' and spend > 500")

# .isin() — multiple value filter
df[df['city'].isin(['Mumbai', 'Delhi'])]

4. Transformation and Feature Engineering

4.1 apply(), map(), and applymap()

# .map() — Series only, element-wise transform or dict lookup
df['city_code'] = df['city'].map({'Mumbai': 'MUM', 'Delhi': 'DEL', 'Pune': 'PUN'})

# .apply() — apply function along axis (row or column)
df['spend_category'] = df['spend'].apply(lambda x:
    'High'   if x >= 2000 else
    'Medium' if x >= 1000 else
    'Low'
)

# .apply() on a row (axis=1) — access multiple columns
def full_label(row):
    return f"{row['name']} ({row['city']})"

df['label'] = df.apply(full_label, axis=1)

# np.where() for vectorized conditional (faster than .apply for simple conditions)
import numpy as np
df['high_value'] = np.where(df['spend'] > 1500, 'Yes', 'No')

# Arithmetic between columns
orders['revenue'] = orders['qty'] * orders['unit_price']

5. GroupBy and Aggregation

Pandas groupby is the Python equivalent of SQL's GROUP BY. It follows a Split-Apply-Combine pattern: split the DataFrame into groups by a key, apply a function to each group, and combine the results.

import pandas as pd

# Basic aggregation
summary = df.groupby('city')['spend'].agg(['count', 'sum', 'mean', 'std'])

# Multiple columns, named aggregations (Pandas ≥ 0.25)
summary = df.groupby('city').agg(
    total_customers = ('customer_id', 'count'),
    total_spend     = ('spend', 'sum'),
    avg_spend       = ('spend', 'mean'),
    max_spend       = ('spend', 'max')
).reset_index()

# Group by multiple columns
df.groupby(['city', 'year'])['spend'].sum().reset_index()

# transform() — returns same-length Series (like SQL window functions)
# Adds each user's city-average spend back to the original row
df['city_avg_spend'] = df.groupby('city')['spend'].transform('mean')
df['spend_vs_city_avg'] = df['spend'] - df['city_avg_spend']

# Pivot tables — two-dimensional groupby with optional margins
pivot = df.pivot_table(
    values  = 'spend',
    index   = 'city',
    columns = 'spend_category',
    aggfunc = 'sum',
    margins = True   # adds row/column totals
)
Worked Example — Cohort Analysis Setup

Find each customer's first purchase month and compute how many customers from each cohort are still active in month 3:

# Step 1: find each customer's first order date
first_order = (
    orders.groupby('customer_id')['order_date']
          .min()
          .reset_index()
          .rename(columns={'order_date': 'cohort_date'})
)
first_order['cohort_month'] = first_order['cohort_date'].dt.to_period('M')

# Step 2: merge back onto orders and compute months since first order
orders = orders.merge(first_order[['customer_id', 'cohort_month', 'cohort_date']],
                       on='customer_id')
orders['months_since'] = (
    (orders['order_date'].dt.to_period('M') - orders['cohort_month']).apply(lambda x: x.n)
)

# Step 3: cohort table — unique customers per cohort-month pair
cohort_table = (
    orders.groupby(['cohort_month', 'months_since'])['customer_id']
          .nunique()
          .reset_index()
)

7. Data Cleaning Patterns

This section covers the most common real-world data quality operations. These patterns appear both in practice and as interview tasks.

7.1 Handling Missing Values

# Detect nulls
df.isnull().sum()             # null count per column
df.isnull().mean() * 100      # null percentage per column
df[df['spend'].isnull()]      # rows where spend is null

# Drop rows / columns with nulls
df.dropna()                    # drop any row with at least one null
df.dropna(subset=['spend', 'city'])  # only if these columns are null
df.dropna(axis=1, thresh=0.5*len(df))  # drop col if >50% null

# Fill nulls — imputation strategies
df['spend'].fillna(0)                       # fill with constant
df['spend'].fillna(df['spend'].mean())       # fill with mean
df['spend'].fillna(df['spend'].median())     # fill with median (better for skewed)
df['spend'].fillna(method='ffill')           # forward-fill (time-series)
df['city'].fillna(df['city'].mode()[0])       # fill categorical with mode

# Group-wise imputation (fill with group median — better than global median)
df['spend'] = df.groupby('city')['spend'].transform(lambda x: x.fillna(x.median()))

7.2 Handling Duplicates

# Detect duplicates
df.duplicated().sum()                  # count of duplicate rows
df.duplicated(subset=['customer_id'])  # duplicate on specific column

# Remove duplicates
df.drop_duplicates(inplace=True)       # removes exact duplicate rows
df.drop_duplicates(subset=['customer_id'], keep='last')
# keep='first' (default), 'last', or False (drop all duplicates)

7.3 Data Type Conversion

# Convert column types
df['customer_id'] = df['customer_id'].astype('int64')
df['spend']       = df['spend'].astype('float64')
df['city']        = df['city'].astype('category')  # memory-efficient

# Parse dates robustly
df['order_date'] = pd.to_datetime(df['order_date'], errors='coerce')
# errors='coerce' turns unparseable strings into NaT instead of crashing

# Convert numeric columns stored as strings
df['revenue'] = pd.to_numeric(df['revenue'], errors='coerce')

7.4 String Cleaning

# .str accessor — vectorized string operations on Series
df['email'] = df['email'].str.strip().str.lower()
df['city']  = df['city'].str.strip().str.title()

# Extract patterns with regex
df['area_code'] = df['phone'].str.extract(r'(\d{3})')

# Replace with regex
df['cleaned'] = df['text'].str.replace(r'[^a-zA-Z0-9\s]', '', regex=True)

# Check for patterns
df[df['email'].str.contains('@gmail.com', na=False)]

7.5 Outlier Detection in Pandas

import numpy as np

# IQR method
Q1  = df['spend'].quantile(0.25)
Q3  = df['spend'].quantile(0.75)
IQR = Q3 - Q1

lower_fence = Q1 - 1.5 * IQR
upper_fence = Q3 + 1.5 * IQR

outliers = df[(df['spend'] < lower_fence) | (df['spend'] > upper_fence)]
clean_df  = df[(df['spend'] >= lower_fence) & (df['spend'] <= upper_fence)]

# Z-score method
from scipy import stats
z_scores = np.abs(stats.zscore(df['spend'].dropna()))
clean_df  = df[z_scores < 3]  # keep only within ±3 SDs of mean

8. Interview Questions

Python / Pandas — Q&A
QWhat is the difference between .loc and .iloc in Pandas?
.loc selects rows and columns by labels — the index labels for rows, and column names for columns. The end of a slice is inclusive: df.loc[2:5] returns rows with index labels 2, 3, 4, and 5.

.iloc selects by integer positions (0-based). The end of a slice is exclusive (like Python lists): df.iloc[2:5] returns rows at positions 2, 3, and 4 — not 5.

The difference is most important when the DataFrame has a non-default index (e.g., customer_id as the index). df.loc[2] fetches the row with label 2, while df.iloc[2] fetches the third row regardless of its label.
QWhen would you use .apply() vs. a vectorized NumPy operation? Which is faster?
Vectorized NumPy operations operate on entire arrays simultaneously using compiled C/Fortran code. They are 10–100× faster than Python loops or .apply() for numerical operations. Whenever the transformation can be expressed as arithmetic, comparison, or a built-in NumPy ufunc, vectorization is always the right choice.

.apply() calls a Python function row-by-row (or column-by-column), which means Python-level overhead on every call. Use .apply() when the transformation cannot be expressed as a vectorized operation — for example, accessing multiple columns with custom logic, calling an external API per row, or performing conditional logic that requires if-elif-else branching with multiple column references.

Rule of thumb: if you can write it with np.where(), arithmetic operators, or built-in Series methods (like .str.contains()), do that. Reach for .apply() only when those options don't cover the logic.
QHow do you handle missing values in Pandas? What are the different strategies?
Detection: df.isnull().sum() gives the null count per column; df.isnull().mean() gives the proportion.

Strategies depend on the nature of the missingness and the data type:
  • Deletion: dropna() — appropriate when nulls are few (e.g., <5%) and appear to be missing completely at random (MCAR). Deleting too many rows reduces power and can introduce bias.
  • Mean imputation: fillna(mean) — for symmetric numerical data. Preserves the mean but reduces variance and can distort correlations.
  • Median imputation: fillna(median) — better for skewed data (e.g., income, order amounts). More robust to outliers than mean.
  • Mode imputation: fillna(mode()[0]) — for categorical columns.
  • Forward/backward fill: fillna(method='ffill') — appropriate for time-series data where the last known value is a reasonable estimate.
  • Group-wise imputation: groupby().transform() — fill with the group's mean/median (e.g., fill missing salary with department-level median). More accurate than global imputation.
  • Model-based imputation: Predict missing values using a ML model (KNN imputation, iterative imputer). Most accurate but computationally expensive.
QWhat is the difference between merge() and concat() in Pandas?
merge() is analogous to a SQL JOIN. It combines two DataFrames based on a common key column (or multiple key columns). It is used when the DataFrames share a meaningful relationship and you want to match records — for example, joining orders to customers by customer_id. The how parameter controls the join type: 'inner', 'left', 'right', 'outer'.

concat() stacks DataFrames along an axis without matching on a key. It is used to combine DataFrames with the same schema — for example, appending monthly export files (axis=0, stack rows) or combining feature sets side by side (axis=1, stack columns). There is no join condition: it is simple stacking.
QWhat does groupby().transform() do, and how is it different from groupby().agg()?
groupby().agg() collapses each group into one row — the output has one row per group. You lose the original row structure; all you have is the aggregated summary.

groupby().transform() computes the aggregation for each group but then broadcasts the result back to the original row-level index — the output has the same number of rows as the input. Every row in a group gets the same group-level value added as a new column.

This is the Pandas equivalent of a SQL window function without PARTITION BY losing the individual rows. Example use: adding a column showing each customer's spending as a percentage of their city's total spend — df['spend_pct_of_city'] = df['spend'] / df.groupby('city')['spend'].transform('sum'). This is impossible with .agg() alone without a subsequent merge.
