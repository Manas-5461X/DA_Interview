# Data Analytics Interview Modules

This project provides a clean, modern HTML dashboard to read through Data Analytics interview preparation modules. It includes 11 modules with interactive sliding transitions to navigate between them.

## Features
- **Sidebar Navigation**: Quickly jump to any module.
- **Next / Previous Controls**: Easily read through modules sequentially.
- **Sliding Animations**: Smooth transitions between module pages.
- **Responsive Design**: Adapts nicely to different screen sizes.

## How to use
Simply open the `index.html` file in your preferred web browser to start reading.

## Deployment on GitHub Pages
This project consists of purely static files (`.html`, CSS, and JS). Yes, you can deploy it directly and easily on GitHub Pages!
1. Go to your repository settings on GitHub.
2. Navigate to "Pages" on the left sidebar.
3. Under "Build and deployment", select "Deploy from a branch".
4. Choose the `main` branch and the `/ (root)` folder.
5. Click **Save**. Within a minute or two, your web page will be live on GitHub Pages!
